## Decisions
- **Accent is a deep editorial blue (#1b3f8f), not the O1 provisional green.** The trust mechanic is "we link the authority"; those authorities read blue, and a green-on-serif surface reads as an eco brand. 9.7:1 on white, so it works for body links and not only for large CTAs.
- **Two typefaces kept as O1 set them** (Inter body / Source Serif 4 headings) — the serif is what makes the big-type editorial direction work, and swapping fonts would have cost a Lighthouse run for nothing.
- **"Annonslänk" marking is unconditional.** `Annonslank` and `PartnerCta` render the disclosure whether or not `affiliateUrl` is filled, so nothing silently changes character on enrolment day.
- **Every template feature is driven by frontmatter**, including which pages get the byrå lead form (hub is `starta-foretag` or `ekonomi`) and whether a page gets a TOC (≥ 4 `##` headings). A lane 2 author writes MDX and nothing else.
- **Headings get `overflow-wrap: break-word`.** Swedish closes its compounds and display type meets words like "Startkostnadskalkylatorn"; they break instead of pushing the viewport.
- **`--color-ink-muted` darkened to #646d79** so muted text clears 4.5:1 on `--color-surface-alt` — that single token was the whole of the Lighthouse accessibility gap.
- **Comparison prices are per-row sourced**, with `sourceUrl` + `sourceDate` rendered under each verdict, rather than one footnote for the table.
