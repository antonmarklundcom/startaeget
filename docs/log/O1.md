# O1 — Foundation

## Built
- Next.js 15 (App Router, TS, Tailwind v4) + Drizzle/mysql2/drizzle-kit/tsx scaffold; `drizzle/0000_init.sql` for `leads`, `subscribers`, `affiliate_clicks`, `tool_results`.
- Content contract: zod schemas (`src/lib/content/schema.ts`) validated at build time, loader (`src/lib/content/index.ts`) as the only path from `content/` to a page, documented in `src/lib/content/README.md`.
- Routing: one `/[slug]/` resolver for hubs, articles, comparisons and pages; `/verktyg/` + `/verktyg/[tool]/` stubs; `/go/[partner]/` (click log → 302, `noindex`, robots-disallowed); `/api/lead`, `/api/subscribe`, `/api/tool-result`.
- Redirects generated from `content/legacy-urls.json` + the category → hub map, plus WordPress noise (`/feed`, `/tag/*`, `/author/*`, `/page/*`, `/wp-admin/*`).
- SEO plumbing: `buildMetadata` (title ≤ 60, description ≤ 155, trailing-slash canonical), `sitemap.ts`, `robots.ts`, `/og/` image route, JSON-LD helpers (Organization, WebSite, Article, FAQPage, BreadcrumbList, SoftwareApplication).
- Design tokens (`src/styles/tokens.css`) + layout shell; `<PartnerCta>` and `<Annonslank>` primitives; bare Article/Comparison/Hub/Page templates for O2 to redesign.
- `content/affiliates.ts` with 26 partners across the §1.2 slots, every `affiliateUrl` empty and a working `fallback`.
- `scripts/verify.mjs` (16 checks, ~50 s), `scripts/expected-urls.ts`, `tests/screenshots.mjs` (2 widths + horizontal-scroll assertion), CI running verify + unit tests and uploading the screenshot artifact on PRs.
- Two exemplar MDX files (`_exemplar-guide`, `_exemplar-jamforelse`) plus `content/comparisons/exemplar-jamforelse.ts` so the templates render real data. O2 replaces all three.

## Decisions
- **One flat `/[slug]/` resolver** answers hub → article → page instead of separate hub routes. A dedicated `/starta-foretag/page.tsx` and a `/[slug]/` catch-all cannot coexist cleanly, and articles must keep their flat legacy paths (§1.4).
- **A `keep` legacy path with no article yet 301s to its hub** (`src/lib/legacy-fallback.ts`), computed from the content on disk. The redirect disappears by itself when a lane 2 phase adds the article, so no config edit is ever needed and no legacy URL 404s in the meantime.
- **Comparison columns are fixed** (`COMPARISON_COLUMNS`: pris, gratisnivå, bäst för, styrka, svaghet). Every comparison uses the same five, so the tables stay comparable and the component never branches.
- **The database is optional at every layer.** `withDb()` returns null with no `DATABASE_URL` and swallows query failures; no form, no `/go/` click and no page can 500 because MySQL is unreachable.
- **Lead forwarding writes our own row first**, then tries VenderCRM with a 10 s timeout; `forwarded_at` stays null on failure so leads can be replayed.
- **`content/hubs.ts`, `nav.ts`, `home.ts`, `tools.ts` shipped as minimal real data**, not stubs — the O1 exit criteria require `/` and `/starta-foretag/` to render. O2 (hubs/home/nav) and O3 (tools) own and replace them; the shapes in `src/lib/content/site.ts` are the contract.
- **Provisional accent** `#0c6b4f` in `tokens.css`. O2 picks and records the final one (§5.2).
